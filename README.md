## Overview

**Lyra** is a Chrome extension for **YouTube Music** that pops out a floating Picture-in-Picture mini player with real-time synced lyrics. Listen to music, follow along with the lyrics, and control playback without switching tabs.

---

## Features

- **Floating Mini Player**: A Picture-in-Picture window that stays visible on top of other active applications.
- **Synced Lyrics**: Real-time, line-by-line lyrics that scroll automatically with your playback.
- **Playback Controls**: Full audio controls (play, pause, skip, rewind, adjust volume, and track progress) directly in the mini window.
- **Repeat & Shuffle**: Toggle queue play modes without returning to the main browser tab.
- **Dynamic Background**: Dynamic ambient color effects that flow based on the current album art.

---

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dinhbinh02/lyra.git
   ```

2. **Load into Chrome**
   - Open `chrome://extensions/`
   - Enable **Developer mode** (toggle in the top right).
   - Click **Load unpacked** and select the `dist` folder (if built) or the root project folder.

3. **How to Use**
   - Open [YouTube Music](https://music.youtube.com) and play any track.
   - Click the mini player button (the PiP icon on the bottom right of the YouTube Music player bar) to pop out the floating player.
